# LinkX

Vanilla HTML/CSS/JS prototype. Run from a static web server (e.g. `python -m http.server 8000`). Each feature owns its own folder, and uses shared navigation and storage. Work in separate branches and merge through PRs.

See CLAUDE.md for the integration contract.
