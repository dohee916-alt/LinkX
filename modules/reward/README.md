# LinkX · 나의 밤하늘 — 최종 M 지도형

390×844 순수 HTML/CSS/JS. 승인된 M01 지도형의 배경·아이콘·별자리 경로를 그대로 동기화합니다. 원본 디자인을 다시 설계하지 않습니다. 자유 드래그·상하좌우 이동, M02 축소(56.27%)·M01 기본(100%)·M03 확대(160%), 기존 중앙 상세와 미션 회고를 유지합니다.

최종 Figma: https://www.figma.com/design/IRJ7lGiMvKZwZ5aTitqQQa/G?node-id=2193-16908

A1 동기화: https://www.figma.com/design/IRJ7lGiMvKZwZ5aTitqQQa/G?node-id=2334-7393 — 기존 리워드 목록 슬롯에 원본을 복제했습니다. 옆 리워드 수령 화면과 같은 76×166, 검은 안쪽 Stroke, 8.654px 모서리와 원본 Glow를 적용했습니다. 원본 M01과 다른 팀 화면은 수정하지 않았습니다.

## 확인 경로

- 팀 전시 루트 → `리워드` → 별 누르기 → `리워드 확인하기` → 보관함
- 전시 메뉴의 `나의 밤하늘` → 보관함 직접 진입
- `/modules/reward/` — 최종 지도 직접 진입
- 지도는 드래그, 휠/트랙패드, 방향키로 이동합니다. +/− 버튼과 키보드 +/−, 터치 핀치를 지원합니다.
- 기존 `?sort=newest` / `?sort=oldest` 및 `LinkXReward.sort()`는 키보드 탐색 순서로 호환됩니다. 지도상의 좌표는 승인된 원본 그대로 유지합니다. 원본 M01에는 정렬 메뉴가 없습니다.
- `/modules/reward/index.html?reward=5` (상세 바로 열기)

05 → 미션 회고 보기 → 상세로 돌아가기 → 닫기를 실제로 사용할 수 있습니다. 더 이상 존재하지 않는 `/modules/feedback/`를 iframe으로 열지 않습니다. 회고는 보관함 내부의 접근 가능한 화면으로 표시하므로 지도의 이동·확대 상태를 유지합니다.

수령 화면에서 보관함으로 들어온 경우 상단 뒤로 버튼은 `modules/mission/index.html?view=reward-3`로 돌아갑니다. 보상 애니메이션을 다시 재생하거나 보상을 중복 획득하지 않습니다.

## 데이터 계약

공통 `shared/store.js`의 `linkx:v1` 스토어를 사용합니다. 다른 팀 데이터는 덮어쓰지 않습니다.

- `unlockedRewards: number[]`: 획득한 보상. 빈 배열은 빈 보관함입니다. 기존 `rewardUnlocked` / `rewards.unlocked`도 읽습니다.
- `rewardRecords: { [rewardId]: { rewardId, missionId?, missionTitle?, acquiredAt?, reflection?, title?, achievement?, next?, source? } }`
- `acquiredAt`: ISO 날짜. 획득한 보상끼리 시각순으로 정렬하고, 미획득 보상은 그 뒤에 둡니다. 예전 시각 없는 전시 데이터는 기존 01→05 획득 순서를 유지합니다.
- `mission.rewardId` 또는 `mission.id === "greeting-05"`로 보상이 명확하게 연결된 경우 `reflection` / `feedbackSummary` / `summary` / `reviewSummary`를 읽습니다. 관련 없는 현재 미션의 요약을 05에 표시하지 않습니다.
- `claimReward(5)`는 재호출해도 기존 획득 시각과 회고를 유지합니다.

기존 전시 기본값은 01–05 획득입니다. 저장 데이터가 전혀 없을 때만, 팀 Figma 및 텍스트모드의 학생회관 인사 보고를 바탕으로 한 05 예시 회고를 제공합니다. 회고 화면에서 `예시 회고`로 표시합니다. 명시적인 획득 목록/기록이 있으면 예시를 섞지 않고, 누락된 회고는 빈 상태로 표시합니다.

01–04의 미확정 획득 조건은 구현에 넣지 않았습니다. 기존 보상명과 의미 설명만 표시합니다. 실사용자 회고를 저장하는 상위 모듈은 위 데이터 계약으로 값을 전달해야 합니다.

## 소재 및 검증

`art/map/*.svg`는 승인된 M01의 원본 SVG 내보내기입니다. 잘린 영역 밖의 소재는 임시 복제본에서 투명 SVG로 추출한 뒤 복제본을 즉시 삭제했습니다. 내보내기에 섞인 조상 Frame/Section 배경만 분리했고 아이콘 Path, 원본 Stroke·그라디언트·필터는 보존했습니다. `map-source.js`는 원본 카메라·별 좌표, `map-assets.js`는 SVG 크기, `map.js`는 원본 경로 및 클릭 노드를 담습니다. 전체 UI를 한 장의 이미지로 대체하지 않았습니다.

실제 보상 데이터는 기존 `data.js`와 공통 스토어 그대로 유지합니다. 01–08의 DOM 노드만 실제 리워드이며 먼 곳의 흐린 추가 도형은 원본의 장식적 미획득 예고입니다. 신규 이름·해제 조건·사용자 데이터를 추가하지 않았습니다. `편집`은 원본의 이름만 있는 비기능 표기를 그대로 유지합니다.

기존 상세·회고 데이터, 직접 진입 URL, 수령 화면으로 돌아가는 공통 라우팅은 유지합니다. 이전 PNG/SVG 자산도 삭제하지 않았습니다.
